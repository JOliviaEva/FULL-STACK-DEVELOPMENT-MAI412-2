About UniAI ERP

UniAI ERP is a demonstration university management platform built to explore how a full stack application might organize student records, faculty information and course data behind a single, coherent interface.

This version is written with plain, hand-authored HTML and CSS — no framework or utility library — using custom properties for the color palette and media queries for the responsive layout.
