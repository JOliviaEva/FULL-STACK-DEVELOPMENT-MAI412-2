# Full Stack Development Lab Work 

A structured repository containing all lab assignments and projects completed for the Full Stack Development curriculum. This repository demonstrates practical implementation of modern web technologies, moving from static layouts to dynamic, database-driven Single Page Applications (SPAs).

**Tech Stack Highlights**
* **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), React.js (Vite)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Tools:** Git, GitHub, NPM, Postman/Insomnia

## Lab Exercises Breakdown

**Unit 1: HTML5, CSS3, and GitHub**
* Developed a responsive webpage layout featuring a header, navigation bar, main content, and footer using Tailwind CSS and the Tailwind Typography plugin.
* Created a multi-section webpage demonstrating proper Git version control (commits, rollbacks) and pushed to a remote GitHub repository.

**Unit 2: Core JavaScript and Client-Side Scripting**
* Implemented a webpage integrating JavaScript objects and HTML5 APIs.
* Built a form with client-side validation and custom event handling (e.g., button clicks, input changes) using vanilla JavaScript.

**Unit 3: Modern JavaScript and Introduction to React.js**
* Built a React application using Vite and Tailwind CSS to fetch JSON data from an external API and display it in a structured format.
* Created a React form application utilizing state management, deployed to a cloud platform (Heroku, Vercel, or Netlify).

**Unit 4: Advanced React.js**
* Developed a complete Single Page Application (SPA) using React.js that performs full CRUD operations utilizing state management.
* Implemented dynamic routing and conditional rendering across multiple components with API integration using React Router and Axios.

**Unit 5: Node.js and MongoDB**
* Demonstrated backend file handling using the Node.js file system module.
* Built and tested simple RESTful services connecting an Express.js server to a MongoDB database.
