1. Semantic Elements

2. HTML5 Audio

<audio controls>
  <source src="song.mp3">
</audio>

Attributes: controls, autoplay, loop, muted

Applications: Music player, Podcasts, Voice assistant

3. HTML5 Video

<video controls width="400">
  <source src="movie.mp4">
</video>

Attributes: controls, autoplay, poster, loop

Applications: E-learning, OTT, Video tutorials

4. Web Storage

Local Storage (Permanent, across tabs) - e.g. Dark mode

Session Storage (Until tab closes, same tab only) - e.g. Login

Browser Cache: Stores webpage resources (images, CSS, JS), large memory capacity.

6. Canvas API

Canvas is used to draw graphics using JavaScript.

<canvas id="myCanvas"></canvas>

Applications: Games, Charts, Drawing applications, Animations

7. Drag & Drop API

  1. dragstart - when dragging begins

8. Web Workers

JavaScript feature that runs scripts in the background. Communicates through postMessage().

Applications: Large data processing, Image and video processing

Quick Notes

  • Local Storage has no expiry.
  • Session Storage clears when the tab closes.
  • Geolocation needs user permission.
  • Canvas draws with JavaScript.
  • Web Workers can't access the DOM.
